# 머니체크

한국어 월간 달력으로 수입·지출·구독을 관리하는 웹 앱입니다. Node.js 24.x에서 실행하며, 로컬에서는 SQLite, Vercel에서는 Firebase Cloud Firestore를 사용합니다. 의존성을 설치한 후 실행하세요. Vercel 설정은 [DEPLOYMENT.md](DEPLOYMENT.md)에 있습니다.

## 실행

프로젝트 폴더에서 다음 명령을 실행하세요.

```powershell
node server.mjs
```

브라우저에서 [머니체크 열기](http://localhost:3100)를 누르세요. 처음 만든 계정이 **JE.KIM 관리자**입니다. 본인의 이메일과 새 비밀번호로 직접 설정하세요. 이후 만든 계정은 일반 사용자입니다. 기본 실행은 이 컴퓨터에서만 접근할 수 있습니다.

개발 중 자동 재시작:

```powershell
node --watch server.mjs
```

## 구현된 기능

- 반응형 월간 달력: 날짜별 수입·지출 합계, 기록된 구독 및 예정 구독 표시.
- 날짜 선택 시 상세 내역, 수입·지출 추가·수정·삭제.
- 기본 수입·지출 카테고리 및 직접 추가.
- 구독 추가, 서비스명·요금·통화 수정, 향후 자동 기록 중단.
- 청구 월을 기준으로 중복 없는 구독 지출 자동 생성. 삭제한 청구분은 다시 만들지 않음.
- 31일 구독의 4월분은 5월 1일, 5월분은 5월 31일에 기록.
- 달러 구독의 결제일 환율 조회, 원화 환산 및 적용 환율·환율 기준일 보관.
- 월별 수입·지출·차액·실제 구독 지출, 카테고리별 지출, 거래 필터 및 검색.
- 결제일 이틀 전부터 앱 내 알림.
- 이메일·비밀번호 가입/로그인, 비밀번호 해시 저장, HttpOnly 세션 쿠키.
- 계정당 세션 하나만 유지. 다른 기기에서 로그인하면 이전 세션을 무효화.
- 관리자 계정 목록 조회와 사용자 이용 정지·재개. 금융 API는 항상 로그인한 사용자 본인의 ID로 제한.
- 이메일 재설정 링크 발송 연동 코드, 30분 일회용 토큰, 재설정 후 기존 세션 폐기.

## 자동 기록과 환율

장부는 한국시간을 기준으로 매년 1월 1일에 새로 시작합니다. 올해 거래만 장부와 대시보드에 표시되며, 계정과 등록한 구독은 이어집니다. 상단의 **장부 저장**에서 연도를 선택하면 해당 연도의 수입·지출을 CSV로 다운로드할 수 있습니다. 이전 기록은 파일 저장을 위해 보관되며, 자동 삭제 시점은 설정하지 않았습니다.

서버가 실행 중일 때 1분마다 미기록 청구분을 처리합니다. 앱에 접속할 때도 처리하므로 서버가 꺼져 있던 기간의 청구분은 다음 실행/접속 때 보충합니다. 로컬 서버가 꺼져 있는 동안에는 실행되지 않습니다. 구독 해지는 해당 외부 서비스의 실제 결제를 취소하지 않습니다.

환율은 [Frankfurter 공식 API](https://frankfurter.dev/)의 USD/KRW 과거 기준 환율을 사용합니다. 휴일 등 공시가 없는 날에는 제공처가 반환한 최근 공시일을 함께 저장합니다. 실제 카드사의 청구 환율·수수료와 다를 수 있으므로 기록된 원화 금액은 직접 수정할 수 있습니다. 조회 실패 시 임의 환율로 기록하지 않고 보류 알림을 표시한 뒤 다음 처리 때 재시도합니다. API 키는 필요하지 않습니다.

구독 요금 변경은 이후 미기록 청구분에 적용합니다. 이미 기록된 금액은 자동으로 덮어쓰지 않습니다. 기존 구독의 결제 주기를 바꾸려면 구독의 자동 기록을 중단하고 새 주기로 등록하세요.

## 이메일 재설정 연결

발송 연동 코드는 구현되어 있지만, 실제 이메일 발송은 서비스 설정 후 사용할 수 있습니다. Resend에서 인증한 발신 주소를 준비하고 서버를 실행하는 PowerShell에 환경 변수를 지정하세요.

```powershell
$env:RESEND_API_KEY = '발급받은 API 키'
$env:MAIL_FROM = '인증된 발신 주소'
$env:APP_URL = 'http://localhost:3100'
node server.mjs
```

설정되지 않으면 재설정 화면/API에서 서비스 미연결 상태를 명확히 알립니다. 이메일에 담기는 주소는 `APP_URL`입니다. 외부 수신자가 사용할 운영 URL 및 HTTPS 배포는 별도 구성이 필요합니다. 환경 변수 목록은 [.env.example](.env.example)에 있습니다. `.env` 파일은 자동으로 읽지 않으며 PowerShell 환경 변수를 사용하거나 `node --env-file=.env server.mjs`로 실행합니다.

## 데이터와 운영 범위

- 모든 계정과 금융 데이터는 `data/moneycheck.sqlite`에 저장됩니다. `DATABASE_PATH`로 저장 위치를 변경할 수 있습니다.
- 백업할 때 서버를 종료한 후 `data` 폴더 전체를 복사하세요. 테스트는 운영 저장소와 분리된 임시 데이터베이스를 사용합니다.
- Vercel 배포용 함수와 PostgreSQL 연결을 지원합니다. 운영 환경에서는 외부 데이터베이스 설정이 필요하며 로컬 SQLite를 임시 디스크에 대신 저장하지 않습니다.
- 외부 배포 시 `APP_URL`, `HOST`, `COOKIE_SECURE=1`을 환경에 맞게 설정하고 HTTPS 프록시, 백업 및 계정 생성 정책을 구성해야 합니다.
- 관리자에게 타인의 금융 내역을 반환하는 API나 화면은 없습니다. 관리자 기능의 현재 범위는 계정 목록과 이용 정지·재개입니다.
- 계정 삭제, 이메일 변경, 결제일 직접 변경은 현재 제공하지 않습니다.

## 검증

```powershell
node --test tests/billing.test.mjs tests/api.test.mjs
```

자동 테스트는 월말 이월·윤년, 로그인·세션 무효화, 계정 간 금융 데이터 격리, 거래 CRUD, 카테고리, 구독 중복·삭제·수정·해지, 달러 환산, 관리자 계정 제한, 일회용 비밀번호 재설정, 교차 사이트 요청과 비공개 파일 차단을 검증합니다. Vercel 함수 시작 및 저장소 미연결 상태, PostgreSQL 쿼리 및 트랜잭션도 검증합니다. 달러 자동 테스트는 고정 환율 캐시를 사용하며 외부 네트워크를 호출하지 않습니다. 실제 공개 환율 API의 응답 형식도 별도로 확인했습니다. 실제 이메일 전송은 발송 서비스 설정 전이므로 검증하지 않았습니다.

브라우저에서 가입, 지출 입력 후 달력/합계 갱신, 구독 등록 후 자동 지출 생성, 휴대폰 너비 화면을 확인했습니다.

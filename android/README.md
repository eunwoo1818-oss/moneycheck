# 머니체크 안드로이드 문자 연결

Android 8.0 이상 전용 개인 테스트 앱입니다. Google Play에 등록하지 않았습니다.

## 설치와 연결

1. 머니체크 웹사이트의 **문자 연결**에서 APK를 내려받아 휴대폰에 설치합니다.
2. 같은 화면에서 **연결 키 만들기**를 누르고 키를 앱에 붙여 넣습니다.
3. 휴대폰의 실제 카드 문자에 표시된 발신 번호를 입력합니다. 여러 번호는 쉼표로 구분합니다.
4. **동의하고 문자 연결 시작**을 누르고 Android의 문자 수신 권한을 허용합니다.
5. 이후 새 문자가 오면 **상태 확인**으로 처리 결과를 확인합니다. 머니체크 달력에서 내역을 확인·수정할 수 있습니다.

새 키는 이전 키를 폐기합니다. 웹에서 **연결 해제**를 누르면 서버가 해당 키의 요청을 거부합니다. 휴대폰의 중지 버튼은 대기 내역과 키를 지웁니다. 이미 전송 중인 요청은 완료될 수 있습니다. 키는 1년 후 만료됩니다.

## 범위와 제한

- 문자 수신(RECEIVE_SMS)만 요청합니다. 과거 문자 조회(READ_SMS), 문자 발송(SEND_SMS), 연락처 권한은 없습니다.
- 지정 번호 + 카드 결제 형태만 HTTPS로 본인의 계정에 전달합니다. 카드 문자 원문은 서버 저장·로그에 남기지 않고 금액·날짜·사용처만 기록합니다.
- 전송 대기 문자와 키는 Android Keystore로 암호화하여 앱 내부에 저장합니다. 앱 백업은 꺼져 있습니다. 대기는 최대 300건, 서버 처리는 수신 후 7일 이내·올해 장부에 한정합니다.
- 현재 지원: `신한카드 2026.11.11 30300 GS편의점` 형식 및 카드사명/승인·취소/단일 원화 금액/`11/11 12:34`/사용처가 있는 일부 문자. 날짜 뒤에 사용처가 있어야 하며, 미지원 형식은 기록하지 않습니다.
- 전체 취소는 **기타 수입(환불)**으로 기록하므로 기존 지출과 환불이 각각 남습니다. 부분 취소·외화·인증·거절·모호한 금액은 자동 기록하지 않습니다.
- MMS·RCS·카드사 앱 푸시·카카오 알림톡은 지원하지 않습니다. 문자 수신 후 JobScheduler가 실행할 때 업로드하므로 절전 상태에서는 지연될 수 있습니다. 강제 종료한 뒤에는 앱을 다시 열어야 합니다.
- 동일 수신 문자 재시도는 중복 저장하지 않습니다. **고정지출에서 이미 자동 생성한 내역과의 중복은 자동으로 합치지 않습니다.** 해당 결제를 두 방식으로 등록했다면 한쪽을 삭제하세요.
- Google Play SMS 권한 심사는 별도이며, 이 APK의 빌드 성공이 심사 통과나 모든 기기에서의 권한 허용을 뜻하지 않습니다. 실제 기기 문자 수신 검증이 필요합니다.

## 개발

JDK 17, Android SDK 36, Build Tools 36.0.0, Gradle 8.13, Android Gradle Plugin 8.13.2를 사용합니다.

```sh
gradle -p android assembleDebug lintDebug
```

Android Studio에서는 `android` 폴더를 엽니다. SDK는 `ANDROID_HOME` 또는 커밋하지 않는 `android/local.properties`로 지정합니다. 설치 파일은 `app/build/outputs/apk/debug/app-debug.apk`에 생성됩니다. 현재 배포 APK는 개인 테스트용 debug 서명입니다. 재배포 시 기존 서명을 유지해야 덮어쓰기 설치가 됩니다.

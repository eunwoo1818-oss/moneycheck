# 아이폰 카드 문자 연결

별도 iOS 앱을 설치하는 방식이 아니라, Apple 기본 ‘단축어’ 앱의 개인용 메시지 자동화에서 머니체크 API로 전달합니다. 실제 아이폰에서 자동화를 만드는 과정은 사용자가 직접 해야 하며, 이 저장소에는 서명된 설치용 단축어나 iCloud 공유 링크가 없습니다.

머니체크 로그인 → **문자 연결 → 아이폰**에 단계별 설정 안내가 있습니다. 웹에서 발급한 키를 `Authorization: Bearer 연결키` 헤더로 사용하고, `https://moneycheck-ivory.vercel.app/api/sms/iphone`에 JSON `{"message":"수신한 카드 문자 본문"}`을 POST합니다. URL이나 요청 본문에 키를 넣지 않습니다.

- 자동화 트리거: 특정 카드사 발신자 및 카드사명이 포함된 메시지. 지원되는 iOS에서 ‘즉시 실행’을 선택합니다.
- ‘텍스트’ 동작에 단축어 입력의 메시지 본문을 지정한 뒤 ‘URL 콘텐츠 가져오기’의 JSON 요청 본문 `message`에 텍스트 동작의 결과를 연결합니다.
- JSON을 직접 문자열로 조립하지 않고 단축어의 JSON 본문 필드를 사용해야 줄바꿈과 따옴표가 안전하게 전달됩니다.
- 응답의 `message`를 알림으로 표시해 처리 결과를 확인할 수 있습니다. 인식할 수 없는 문자는 기록하지 않습니다. 통신 실패 시 자동 재시도/오프라인 큐는 제공하지 않습니다.
- 같은 날 본문이 완전히 같은 문자(앞뒤 공백 및 줄바꿈 방식 차이는 무시)는 중복으로 취급합니다. 실제로 동일한 결제가 반복되었다면 직접 확인해야 합니다. 안드로이드와의 교차 기기 중복 방지는 보장하지 않습니다.
- 키는 1년간 유효하며 기존 안드로이드와 같은 계정별 연결 키를 사용합니다. 새로 발급하면 이전 키는 폐기됩니다. 금융 내역 조회 권한은 없으며 자신의 문자로 내역을 추가하는 용도입니다.
- 실제 iPhone의 수신 트리거·잠금 상태 실행·변수 속성 이름은 기기와 iOS 버전에 따라 확인이 필요합니다. 이 환경에서는 API와 웹 설정 화면을 검증하며 실제 iPhone 수신 테스트를 대신할 수 없습니다.

Apple 공식 설명: [메시지 자동화 트리거](https://support.apple.com/en-ae/guide/shortcuts/apdd711f9dff/ios), [POST·JSON 요청 구성](https://support.apple.com/en-mt/guide/shortcuts/apd58d46713f/ios).
